# deadfiles

**Trouve les fichiers JS/TS que plus aucun autre fichier n'importe.**

Zéro dépendance · Node.js 18+ · Windows, macOS, Linux.

## Utiliser tout de suite (sans rien installer)

```bash
npx github:zrk-lol/deadfiles
```

## Installer la commande `deadfiles`

```bash
npm install -g github:zrk-lol/deadfiles
deadfiles
```
